# Plan de ahorro feature bancario --- Features y beneficios

## Features

-   Simula el retorno en el tiempo con intereses.
-   Genera plan de ahorro.
-   Dependiendo del monto que tenga, puede acceder a otros beneficios,
    por ejemplo un crédito teniendo como garantía el valor del ahorro,
    pero inmediatamente se congela el valor que puede retirarlo.
-   Ahorro desde 10 USD mensuales sin tope.
-   Da opción de bloquear el ahorro para ganar más interés.
-   A través de un stepper el usuario elige su objetivo, monto, interés,
    tiempo y confirmación.
-   Permite crear varios planes de ahorro.
-   Reportes con su historial de planes de ahorro.
-   Débito automático desde cuenta.
-   Se puede elegir la fecha del débito.
-   Notificaciones del sistema: débitos, expiración del plan de ahorro,
    fechas, etc.
-   Visualización de hitos en el progreso.
-   Comparador de escenarios para la simulación del plan de ahorro:
    -   El usuario elige el monto de ahorro.
    -   El usuario ingresa sus gastos mensuales.

## Beneficios para el banco

-   Activos inmediatos.
-   Se asegura el dinero en ahorro por más tiempo.
-   Provee educación bancaria al usuario.
-   Ayuda a disminuir las objeciones.
-   Barrera de entrada baja para captar un segmento joven.
-   Se generan intentos de cobro por la cuota pendiente a días; si en
    este tiempo no logró recaudar, la siguiente temporada de cuota se
    debitarán las dos.
-   Permite levantar datos de dónde se detienen los usuarios al momento
    de generar el plan.
-   Visualización de metas mediante barras de progreso y badges/medallas
    por consistencia, y bonificaciones de tasa de interés al cumplir
    hitos.

## Beneficios para el cliente

-   Puede ganar más intereses.
-   Tener un objetivo de ahorro planificado desde el inicio.
-   Permite tener varios objetivos de ahorro.
-   Puede ver exactamente cuánto dinero tendrá al final del período.
-   Puede iniciar con poco y crecer sin límite.
-   El interés varía dependiendo del valor meta del ahorro y del tiempo
    del mismo.
